## How it works

The portal automatically looks for each image at
`/products/natural-stacks/<slug>.png`. If an image is present, it shows; if
it's missing, the brand's colored initials tile shows instead. So you can
upload images incrementally — no code changes needed.

most often. The rest can come later.
